blackbillKeyboard — Features & Keymap

Full-size ANSI · WeAct Black Pill STM32F401 · QMK Firmware · 2 layers · RGB underglow

Features

Full-size ANSI

All 104 ANSI keys in the matrix.

Two layers

Base layer, and an FN layer on the Fn key (momentary). Media, RGB and bootloader live here.

RGB underglow

16 × WS2812B (2 × 8-LED strips) under the case. Toggle, effects, hue/sat/val/speed on the FN layer.

Bootmagic

Hold the top-left key (Esc) while plugging in to enter the bootloader.

NKRO

N-key rollover — all keys register simultaneously.

Mouse keys

Cursor control from the keyboard (available as keycodes).

Extra keys

Media and system keycodes (volume, transport, etc.).

Base layer

normal key Fn (hold for layer 1)

FN layer (hold Fn)

Dimmed keys fall through to the base layer unchanged. Green keys are the FN remaps.

remapped on FN same as base
FN + Pause or FN + Esc = QK_BOOT (enter the bootloader). Numpad = RGB underglow. Arrows = media transport, Space = mute, FN + F12 = lock the keyboard (press again to unlock).

Build & flash

From a QMK MSYS / QMK environment, in the firmware checkout:

qmk compile -kb blackbillkeyboard -km default
qmk flash -kb blackbillkeyboard -km default

Enter the bootloader one of three ways:

  • Bootmagic: hold the top-left key (Esc) while plugging in the USB cable.
  • Reset button on the Black Pill.
  • Keycode: FN + Pause or FN + Esc (QK_BOOT).

Artifacts land in .build/blackbillkeyboard_default.{bin,hex,elf}.
