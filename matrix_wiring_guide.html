blackbillKeyboard — Hand-Wire Matrix Guide

Full-size ANSI · 104 keys · 6 × 21 matrix · WeAct Black Pill STM32F401 · diode direction COL2ROW

How this matrix is organised

Every switch connects one of the 6 row wires to one of the 21 column wires through a diode. The microcontroller scans one row at a time and reads the 21 columns, so a key is identified by its (row, column) coordinate. That coordinate is exactly what keyboard.json stores for each key.

The physical rows use different numbers of keys (16/21/21/16/17/13), but they all share the same 21 column wires. Cells shown as empty in the grid below simply have no switch at that coordinate — the wire still passes by.

1 · Diode orientation (COL2ROW)

For COL2ROW the diode sits on the switch's row leg, and the black band (cathode) faces the row wire, away from the switch. The plain lead (anode) connects to the switch, which is on the column side. A mnemonic is the symbol >|: current only flows from the column, through the switch, and out to the row.

Do this identically for all 104 switches — all diode bands facing the same direction (toward the row). Do not mix orientations.

4 · Wiring steps

  1. Diodes first. Solder one 1N4148 (or similar) to every switch, band facing the row side as shown in §1. Chain each physical row of diodes together into a single row wire.
  2. Row wires. Six row wires. Solder the diodes of each physical row together, then run each row wire to its MCU row pin (R0–R5 in §2).
  3. Column wires. Twenty-one column wires. Connect the free switch leg of every key that shares a column index. Route column 0 (C0) through all keys listed in column 0 of the grid, and so on. Run each to its MCU column pin.
  4. RGB underglow. Data-in → B0 through a 330 Ω resistor. Power the strips from 5V/GND with a 1000 µF electrolytic across the rails. Chain 2 × 8 LEDs (16 total); the data-out of strip 1 feeds data-in of strip 2.
  5. Controller. Bring every row/column wire to the Black Pill and keep a written map of pin → row/col. Column 4 goes to B4; A10 is left unused so no pull-up is needed there (see the pin caveats). Mount the controller so USB is reachable.
  6. Test. Flash the firmware, then use a keyboard tester. If a whole row or column is dead, reflow that wire; if a single key is dead, check that switch and its diode.
These pins are the firmware's pins. The values here match keyboards/blackbillkeyboard/keyboard.json (rows A0–A5, 21 columns, RGB B0). Wire the board to match the firmware — if you change any wire, update keyboard.json so the two stay in sync. Run qmk info -kb blackbillkeyboard to confirm the layout and pins the firmware expects.
